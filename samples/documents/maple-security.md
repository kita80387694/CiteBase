# Maple 安全设计

Maple 登录会话有效期为 8 小时，注销后立即失效。

Maple 密码最小长度为 12 个字符，并禁止使用演示密码进入生产环境。

Maple 在数据库查询条件内同时限制资源 ID 和 tenant_id。

Maple 日志禁止记录明文密码、访问令牌和完整 API Key。

Maple 未认证访问返回 HTTP 401，无权访问的资源统一返回 HTTP 404。

Maple 文件上传允许 .txt、.md 和 .pdf 扩展名，仍需解析验证内容。

Maple 密钥通过环境变量注入，不写入 Git 仓库。

Maple 同一账号连续登录失败 7 次后锁定 15 分钟。

Maple 管理员操作记录操作者、目标资源、时间与操作结果。

Maple 将上传文档视为不可信数据，文档内的指令不得改变系统规则。

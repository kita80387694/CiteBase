# 简历表述（基于已验证事实）

以下三条可用于项目描述；不要改写成生产规模、线上用户或不存在的性能提升。

1. 独立工程化实现 CiteBase 知识库问答与评测平台，采用 Java21、SpringBoot、SpringAI、PostgreSQL/pgvector 与 React；参考 rag-from-scratch 的索引/检索/生成思路，自行实现登录隔离、文档版本原子切换、内容哈希去重与未变分块embedding复用。
2. 设计数据库持久索引任务、有限重试及重启恢复机制，在检索SQL内落实用户过滤，校验回答引用来自本次证据集合；通过36项后端测试（含真实 Docker Testcontainers 核心6项、RAG 5项）、Docker 中52 条真实 HTTP 断言、33 条真实安全断言及浏览器链路验证，覆盖并发删除、失败保旧索引、供应商超时/限流协议与越权风险。
3. 构建58题原创可分发评测集，使用 DeepSeek-V3.2 与 BGE-M3 完成116条真实向量/关键词RRF对比：50个可回答题的 Recall@5 均为1.00，MRR分别为0.9900与0.9667；如实保留混合未优于向量的结论，默认向量检索。记录模型、数据版本、逐题证据及原始结果，区分引用有效、证据命中和未人工评分的答案正确性；上述数据只代表本次小样本，不声称泛化效果或生产性能提升。

开源边界：没有复用未明确许可的notebook代码，没有把教程已有能力计入新增成果；本项目新增的权限、版本、任务恢复、引用验证、评测与界面均有对应实现。不是企业生产系统，不能宣称大规模吞吐、商业部署或形式化消除提示注入。

# 五分钟演示

演示前启动服务，运行 `node scripts/seed-demo.mjs --evaluate`。检查右上角模式；mock只能讲工程流程，真实结论必须引用real结果。

1. **0:00–0:40 登录与隔离**：使用alice登录，查看“CiteBase 自建手册 v1”；另一个窗口用bob，展示知识库列表相互独立。用 `node scripts/verify-api.mjs` 展示跨用户引用/检索/任务/评测均404的验证记录。
2. **0:40–1:30 索引生命周期**：查看5份样例文档SUCCESS及处理任务尝试次数。重复上传atlas-api.md确认不新增；更新一个段落，展示新版本成功后切换。说明失败保留旧索引的数据库风险测试。
3. **1:30–2:40 有来源问答**：问“Atlas API 默认监听哪个端口？”，点击引用查看文件、页码、段落及片段。切换向量/混合检索，展开实际检索候选。问不存在的财务问题，检查拒答；若模型错误回答，照实记录失败，不掩盖。
4. **2:40–4:15 评测**：导入samples/evaluation.json，展示50个有答案和8个无答案题。为避免等候，可打开预先完成的结果；比较Recall@5、MRR、两类耗时，打开一题看标注证据、检索列表、回答、引用有效性。强调“答案判定未评分”不等于正确。
5. **4:15–5:00 工程验证**：导出JSON查看模型、dataVersions与参数。展示docs/PROGRESS.md、测试记录、已完成的真实结果及开源参考边界。最后解释900/700分块、等权RRF和关键词中文bigram局限。

备用：无模型额度时使用mock，但不可展示mock检索指标作为模型性能成果；Docker异常时可用README本地开发方式。真实验证未通过时应说明原因，不能替换成mock并称完成。
